# Mord3rca's Buildroot Tree

A collection of Buildroot packages and products

## Setup

This external tree can be setup according to [Buildroot's documentation](https://buildroot.org/downloads/manual/manual.html#outside-br-custom)
or by using [Mord3rca's workspace](https://github.com/Mord3rca/repo-workspace).

## Products

* [francis](https://github.com/Mord3rca/francis): A VPN home server compatible with OpenWRT based travelling router

## Packages

* [dyndns-updater](https://github.com/Mord3rca/dyndns-updater): A set of BASH scripts to update a DynDNS entry

* [grepcidr](https://github.com/pivpn/grepcidr): Filter IPv4 & IPv6 addresses matching CIDR patterns

* [pivpn](https://github.com/pivpn/pivpn): The simplest VPN installer, designed for Raspberry Pi
